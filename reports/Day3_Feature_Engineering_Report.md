# Time Series Decomposition

Seasonal decomposition was performed using an additive model.

### Components Analyzed

- Trend
- Seasonality
- Residual

### Observation

#### Trend

The trend component reflects the long-term movement of children in HHS care over the observation period.

#### Seasonality

Weekly seasonal fluctuations may be observed, indicating recurring operational patterns.

#### Residual

Residual values represent random fluctuations not explained by trend or seasonality.

---

# Stationarity Test

The Augmented Dickey-Fuller (ADF) test was performed to determine whether the target time series is stationary.

### Code

```python
from statsmodels.tsa.stattools import adfuller

result = adfuller(df["Children in HHS Care"])
```

### Recorded Metrics

- ADF Test Statistic
- p-value
- Critical Values

### Decision Rule

- p-value < 0.05 → Stationary
- p-value ≥ 0.05 → Non-Stationary

If the series was non-stationary, first-order differencing was applied.

```python
df["HHS_Diff"] = df["Children in HHS Care"].diff()
```

The ADF test was repeated after differencing.

# Feature Engineering

Several predictive features were created to improve forecasting performance.

---

## Lag Features

Created:

- Lag_1
- Lag_7
- Lag_14

### Purpose

Lag features provide historical information that helps forecasting models learn temporal dependencies.

---

## Rolling Mean Features

Created:

- Rolling7
- Rolling14

### Purpose

Rolling averages smooth short-term fluctuations and capture medium-term trends.

---

## Rolling Standard Deviation

Created:

- RollingStd7

### Purpose

Measures short-term variability in HHS care demand.

---

## Net Pressure Feature

Created:

```text
NetPressure =
Children transferred out of CBP custody
−
Children discharged from HHS Care
```

### Purpose

This feature estimates operational pressure on the HHS care system.

Higher values may indicate increasing demand for shelter capacity.

---

## Calendar Features

Created:

- DayOfWeek
- Month
- Quarter
- WeekOfYear

### Purpose

Calendar features allow machine learning models to identify weekly, monthly, and seasonal patterns.
